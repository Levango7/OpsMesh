总览

把六块能力（运维 / 配置库 / 部署 / 编排 / 日志 / 告警）的关键指标汇到一屏，先看清全局，再进具体模块。点任意数字卡片可直达对应模块。

怎么用？
给第一次用的你：
· 总览：把六块能力（运维 / 配置库 / 部署 / 编排 / 日志 / 告警）的关键指标汇到一屏。
· 上方四个彩色数字卡片是全局概览，点任意一个可直达对应模块。
· 下方「运维能力方向」是六大能力入口，点卡片进入对应功能模块。
· 「快捷入口」可一键直达各模块；图表区展示任务健康、告警级别、资源分布与网段拓扑。

运维能力方向

OpsMesh 个人版围绕网段设备提供 6 大运维能力，点击卡片进入对应功能模块。

设备纳管自动发现网段设备、安装 agent、纳管上线
任务执行远程执行 shell 命令、查看结果、失败重试
配置下发远程写文件、配置项管理（CMDB）
服务管理远程启停系统服务、查看服务状态
文件分发远程文件写入、批量分发
状态监控CPU/内存/磁盘/网络实时指标、告警

快捷入口

点任意一项直达对应模块。

数据从哪来？

设备接入网段后被自动纳管；任务下发到采集端执行；失败进入死信并触发告警；日志与指标持续采集。这一切在左侧六个模块中分别管理。

任务健康

最近任务的执行结果分布（成功 / 失败 / 其余）。

今日任务成功率趋势

按创建小时统计的成功率（成功 ÷ 终态任务）。悬停看点明细；柱高为当小时任务量。

告警级别

当前活跃告警按严重度（严重 / 警告）分布。

资源类型分布

按设备类型（物理机 / 虚拟机 / 容器 / Pod / 中间件 / 数据库 / 脚本任务）统计数量。

网段拓扑

控制面与各网段（按设备 IP 归属 CIDR）的设备分布，一屏看清网络分域。

运维中枢

这里集中管理「设备」和「任务」：把命令下发给设备上的采集端去执行，查看纳管状态，跟踪失败与告警。上方彩色数字卡片是全局概览，也可在左侧「总览」一屏纵览。

怎么用？
给第一次用的你：
· 采集端（Agent）：部署在每台设备上的小程序，负责接收并执行控制面下发的任务。
· 网段 / 设备：设备按所属网段分组，控制面发现后会自动纳管。
· 下发任务：选一台采集端 → 选类型（执行命令 / 启停服务 / 下发文件）→ 填内容 → 下发。
· 点设备行可看详情；任务或设备失败会用红色高亮。
