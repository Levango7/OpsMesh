企业版前端未内置于本二进制

控制面已在 /enterprise/ 就绪，但构建这个二进制时没有把企业版前端产物（Vue3 + Vite）打包进去。

这是源码构建的正常结果：企业版前端需要 Node.js 构建，官方镜像与发布包已内置，源码构建请先执行组装脚本。

bash deploy/docker/scripts/build-enterprise-web.sh
go build ./cmd/opsmesh

如果使用 Docker 部署（deploy.sh up / docker-compose / Helm），请重新构建控制面镜像——镜像内已包含 Node 构建阶段，无需本地 Node 环境。
