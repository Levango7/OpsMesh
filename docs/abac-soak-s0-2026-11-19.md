## 5. Anomalies and findings

### A1 — `policy-create` cannot author a deny policy (blocking for real soak authoring)

`internal/controlplane/abac_ops.go:222-233` always persists
`Effect: "allow"` when handling `policy-create`; the request body has no effect
field. The bundle/evaluator supports deny-overrides, but there is no supported REST
path to create a deny policy. The two deny policies in this run were inserted
directly into `abac_policies` and loaded by the controlplane at startup.

Impact: the production soak needs explicit deny policies (the plan requires two
denies in S0 and deny coverage later). Until deny authoring is supported (API or
GitOps/file path), the soak depends on an out-of-band SQL/manual step, which is not
auditable through the product.

### A2 — transient MySQL store stall caused one bundle 401 and a gRPC cooldown

At `15:45:56–15:46:04 +08:00`, both agents logged gRPC connection failures and
entered a 5–8s circuit-breaker cooldown; at `15:46:03` the controlplane logged
`agent HMAC 认证失败` for `soak-s0-deny` and a bundle `401`. Controlplane store logs
at the same instant show `Heartbeat 更新失败 ... context deadline exceeded` and
`Agent 查询失败 ... context deadline exceeded`. The agent kept its LKG bundle
(`ABAC 策略包请求被拒绝（401/403），保留现有缓存`) and continued. No decision rows
were lost, and the next bundle requests were 304.

This is a **local single-node infrastructure stall**, not an ABAC logic failure, but
it shows that a store latency spike turns into an authentication 401 rather than a
retryable 5xx. For the real soak, store latency must be alarmed separately and the
401-vs-5xx classification should be reviewed (a failed secret lookup is not a
credential failure).

### A3 — empty task queue is logged at ERROR every dispatch tick

`task-svc` returns gRPC `NotFound` for an empty queue; the agent logs
`领取任务失败 ... task not found` at **ERROR**. With `--task-dispatch-interval=1s`
and 2 agents this produced **789 ERROR lines in ~7 minutes**. This is not an ABAC
metric, but it will bury real errors and will fire error-rate alerts during the
soak. The idle path should log at debug/rate-limited, or map empty queue to a
non-error result.

### A4 — registration did not return the per-agent HMAC secret

Agents registered successfully but the response carried no secret; the ABAC HTTP
client refused to start until `agent.key` was provisioned from `agents.secret`
(the D2 workaround from the M1–M3 dogfood). This is expected for a bare local
registration without install-token/TLS delivery, but the soak automation must
provision the key deterministically and not assume the registration response
contains it.

### A5 — Windows cannot assert file mode 0600

The LKG cache is written through the 0600 code path, but Win32 `os.Stat` does not
expose Unix mode bits (same platform limitation as dogfood D4). POSIX mode 0600
must be asserted on the Linux production path.

## 6. What must be true before the S15 review

S0 only proves the mechanism. Before treating the soak as evidence toward D8/D13
(and before any S15 review):

1. **Export reporter counters.** `ABACDecisionReporter.Stats()` must be exposed
   (structured log every 5 min or Prometheus) with `accepted/failed/dropped/buffered`.
   Without it the `<0.1%` dropped gate cannot be computed; this is the plan's §3.2
   D0 observation gap and remains a **hard D9 blocker**.
2. **Run the real cohort, not synthetic agents.** Freeze the 12 staging and 40
   `prod-edge-a` devices from CMDB at D0, record device/agent/version/capability,
   and keep them shadow for 7×24h. Two local agents are not a cohort.
3. **Production-like infrastructure.** Multi-node controlplane/MySQL/Redis with
   HA latency and disk behavior; validate the 720h retention sweep against
   `received_at`; confirm MySQL reconnect and Redis outage do not break signing.
4. **Supported deny-policy authoring.** Provide an audited policy-create/update
   path that persists `deny` (or a declared GitOps seed path), then verify deny
   propagation in the signed bundle without direct SQL.
5. **Daily deployed parity.** Replay all 32 shared fixtures against the deployed
   controlplane and a live agent (0 divergence), and run the 100-sample live
   divergence proxy with ≥95% coverage (needs the `abac:read` service account).
6. **D7 kill-switch drill.** Prove TTR ≤5 minutes end-to-end, including config
   delivery and agent restart, and record per-device recovery.
7. **Log/alert hygiene.** Remove or rate-limit the empty-queue ERROR noise; alarm
   on signature failures, store-latency timeouts, 401/403 bundle fetch, and
   decision-upload non-202; explain every deny.
8. **Would-deny trend.** Measure the real critical-path shadow would-deny rate;
   if it is ≥1%, stop and return to the RBAC→ABAC baseline before any enforcement.
9. **Treat S0 as day-0 rehearsal only.** The plan's D0 preflight checklist (§3.3)
   is still required on the real pools; S0 does not satisfy it.
