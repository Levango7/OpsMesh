## 状态口径

| 状态 | 含义 |
|---|---|
| **待批准** | 立项书已写出，等待 owner 对范围、依赖或排期拍板；未开始施工 |
| **已立项** | owner 已批准，已有明确的里程碑与验收口径；可以排期施工 |
| **进行中** | 已有批次在施工，里程碑有实际进度 |
| **已收口** | 验收标准全部满足，债务台账对应行已关闭 |

## 阅读顺序

1. 先看本表的「状态」与「工作量」，判断是否与当前交付目标冲突。
2. 再看立项书的 §2（证据）与 §4（非目标），确认没有把「已收敛」重复计债、也没有悄悄扩大范围。
3. 最后看 §6（DoD）与 §8（回滚）：没有可执行验收与回滚方案的项目不进入排期。
