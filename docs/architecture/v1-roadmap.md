## 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 持久化迁移数据丢失 | 中 | 高 | 双写 + 校验 + 回滚脚本 |
| 微服务网络延迟 | 高 | 中 | 同可用区部署 + 连接池 |
| 前端性能瓶颈 | 中 | 中 | CDN + 懒加载 + 虚拟滚动 |
| 安全漏洞 | 中 | 高 | 定期渗透测试 + WAF |
| 人员不足 | 高 | 高 | 优先 P0 + 自动化 |
